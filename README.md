## 試算表欄位規則

- A 欄：歌名
- B 欄：歌手
- C 欄：歌曲分類 / 標籤
- D 欄：歌曲連結（可空）
- F 欄：網站上方標籤按鈕清單

如果網站讀不到資料，請確認 Google Sheet 分享權限是「知道連結的任何人」可以「檢視」。
